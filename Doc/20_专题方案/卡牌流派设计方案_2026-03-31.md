# 卡牌流派设计方案

> 状态：草案 · 2026-03-31
> 背景：基于当前机制（3 房间、1 租客 + 3 设备槽、耐久/等待、指数贷款、13 种效果）梳理可行流派方向。

---

## 核心张力

流派围绕以下决策轴分化，卡牌设计需要在这些轴上站位明确：

| 张力 | 两端 |
|------|------|
| **时间** | 低耐久高租金 vs 高耐久低租金 |
| **空间** | 填满房间最大化收益 vs 保留空房触发特殊效果 |
| **节奏** | 前期投资攒经济 vs 后期爆发过贷款关 |
| **资源** | 花钱打牌 vs 留钱抗贷款 |

---

## 六个流派

### 1. 稳租长线流（Steady Rent）

**核心思路**：高耐久租客 + 续租设备，一套阵容吃到底。

| 卡槽 | 方向 |
|------|------|
| 租客 | 中等 baseRent、高 durability（6-8）、低 cost |
| 设备 | settleEffect: `AddTenantDurability`，续命核心 |
| 合同 | 每回合额外 +durability 或降低贷款压力 |

- **弱点**：单次收入低，怕指数贷款后期碾压
- **关键词**：续租、耐久回复、低维护成本

---

### 2. 快速周转流（Quick Turnover）

**核心思路**：低耐久高租金租客，频繁更替，靠 destroyEffect 和事件补差价。

| 卡槽 | 方向 |
|------|------|
| 租客 | 高 baseRent、低 durability（2-3）、destroyEffect 给补偿金而非扣钱 |
| 设备 | settleEffect: `DrawCard`，加速手牌循环 |
| 事件 | `SpawnRandomTenantInSelectedRoom`，空位立刻补人 |
| 合同 | 租客销毁时触发额外收益（需新效果） |

- **弱点**：依赖手牌质量，空窗期没收入
- **关键词**：高流转、销毁奖励、抽牌加速

---

### 3. 设备堆叠流（Equipment Stack）

**核心思路**：3 个设备槽全填满，叠加 settleEffect 放大单个租客收益。

| 卡槽 | 方向 |
|------|------|
| 租客 | 中等 baseRent，普通耐久，活着就行 |
| 设备A | settleEffect: `AddMoney;X`（固定加成） |
| 设备B | settleEffect: `MultiplyRoomSettlement`（乘区效果，需新效果） |
| 设备C | `AddTenantDurabilityInSelectedRoom`，保租客不掉线 |
| 合同 | 降低设备 cost 或延长设备耐久 |

- **弱点**：前期投入大，租客到期整套白搭
- **关键词**：设备协同、乘区收益、保护投资

---

### 4. 空房经济流（Vacancy Economy）

**核心思路**：反直觉 — 故意空房，靠 `AddMoneyByEmptyRooms` 赚钱。

| 卡槽 | 方向 |
|------|------|
| 事件 | `EvictTenantInSelectedRoom` + `MoveTenantToEmptyRoom`，主动调配 |
| 合同 | settleEffect: `AddMoneyByEmptyRooms;X`，空房越多越赚 |
| 租客 | 少量高耐久租客集中在一个房间，其余房间空置 |

- **弱点**：天花板明显（最多空 2 个房），需要 `ExpandSlot` 或加房间打破上限
- **关键词**：空置收益、租客调度、反常规策略

---

### 5. 扩张流（Expansion）

**核心思路**：`ExpandSlot` 突破默认 1 租客限制，多租客叠租金。

| 卡槽 | 方向 |
|------|------|
| 事件/设备 | `ExpandSlot;1`，扩容让一个房间放 2-3 个租客 |
| 租客 | 中低 cost、中等 baseRent，数量取胜 |
| 设备 | `TriggerSelectedRoomSettle`，满员房间双倍结算 |
| 合同 | 按房间人数加成（需新效果：`AddMoneyByTenantCount`） |

- **弱点**：耐久管理困难，人越多到期越乱
- **关键词**：扩容、多租客、规模效应

---

### 6. 爆发结算流（Burst Settlement）

**核心思路**：`TriggerSelectedRoomSettle` 让关键房间一回合结算多次。

| 卡槽 | 方向 |
|------|------|
| 设备 | settleEffect: `TriggerSelectedRoomSettle`，额外触发一次结算 |
| 租客 | 高 baseRent 单体，配合多次结算收益翻倍 |
| 合同 | 每 N 回合自动触发一次额外全房间结算 |

- **弱点**：依赖特定组合，缺一个零件就不转
- **关键词**：多次结算、单房爆发、组合依赖

---

## 流派交叉点

好的流派不互斥，在关键卡上有交叉：

```
稳租长线  ←→  设备堆叠      设备续租客命，两个流派共享续租需求
快速周转  ←→  扩张          空位多 + 频繁补人，自然协同
空房经济  ←→  爆发结算      集中一房 + 空其余，攻防兼备
```

---

## 需要新增的效果

现有 13 种效果不足以完整支撑全部流派，以下为建议新增：

| 效果 ID | 参数 | 用途 | 支撑流派 |
|---------|------|------|----------|
| `MultiplyRoomSettlement` | `factor` | 房间结算收入乘以倍率 | 设备堆叠、爆发结算 |
| `AddMoneyByTenantCount` | `amountPerTenant` | 按全场租客总数加钱 | 扩张 |
| `AddMoneyOnCardDestroyed` | `amount` | 卡牌销毁时获得金钱（正向补偿） | 快速周转 |
| `ReduceCostForType` | `type;amount` | 降低特定类型卡的费用 | 各流派合同支撑 |
| `AddRoom` | — | 增加一个新房间 | 扩张、空房经济 |
