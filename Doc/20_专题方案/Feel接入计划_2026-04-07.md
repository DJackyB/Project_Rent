## 新增代码

所有新增代码放在 `Assets/_Assets/Scripts/Integration/Feel/`，不进入 `Martian/Feedback/` 目录。

### CompositeFeedbackPlaybackBackend

实现 `IFeedbackPlaybackBackend`。持有一个主后端和一个副后端。

核心行为：
- `Publish` / `PublishSequence`：先调主后端拿到 handle，再调副后端（丢弃其 handle）；只返回主后端 handle。
- `IsAvailable`：取主后端的 IsAvailable；副后端不可用时不影响主后端判断。
- `AllPlaybackCompleted`：只订阅主后端的事件并转发。
- `Configure`：转发给两个后端。
- `Attach`：转发给两个后端。
- `Clear`：先 Clear 副后端，再 Clear 主后端。副后端 Clear 抛异常时 catch + LogError，不阻断主后端。

### FeelFeedbackBackend

实现 `IFeedbackPlaybackBackend`。把 `FeedbackRequest` / `FeedbackSequenceRequest` 映射到配置好的 `MMF_Player` 视觉预制体。

映射规则：
| FeedbackCategory | 对应 MMF_Player 字段 | 是否必填 |
|---|---|---|
| Money（NumericDelta > 0）| `_moneyDeltaPlayer` | 可选 |
| Cost（NumericDelta < 0）| `_moneyDeltaPlayer` | 可选 |
| Settlement | `_settlementStepPlayer` | 可选 |
| Loan | `_loanPaymentPlayer` | 可选 |

另有两个不走 FeedbackCategory 的预制体：
- `_cardPlayPlayer`：由 UI 层直接调用（`UICardDragController` 出牌成功时）
- `_rewardRevealPlayer`：由 UI 层直接调用（`UICardRewardPanel` 出现/选择时）

`IsAvailable` 规则：
- 至少有一个 `MMF_Player` 引用非 null → `true`。
- 全部为 null → `false`。

单条请求找不到对应 `MMF_Player` 时：`Debug.LogWarning` 并跳过该条，不阻断主后端，不返回有效 handle。

`Publish` / `PublishSequence` 返回的 handle 始终立即 Complete（Feel 动画不参与时序控制）。

### BaoZuPoFeelFeedbackInstaller

独立 MonoBehaviour，**不挂在** `FeedbackBootstrap` 所在的 GameObject 上（`FeedbackBootstrap` 标记了 `[DisallowMultipleComponent]`）。推荐挂在同一 Canvas 下的独立子节点。

字段：
- `[SerializeField] private FeedbackBootstrap _bootstrap;`
- 5 个 `[SerializeField] private MMF_Player` 字段（对应上面的映射表）

生命周期：
- `Awake`：检查 `_bootstrap == null`，如果为 null 则 `Debug.LogError` 并 `enabled = false`。检查所有 `MMF_Player` 引用，缺失任何一个时 `Debug.LogWarning`（单个缺失不阻断启动）。
- `Start`：构造 `FeelFeedbackBackend`（传入 MMF_Player 引用），构造 `CompositeFeedbackPlaybackBackend`（主 = null 让 Coordinator 自己的 FloatingText 作为主，副 = FeelFeedbackBackend），调用 `_bootstrap.SetBackend(composite)`。
- `OnDestroy`：调用 `_bootstrap.SetBackend(null)`，让 Coordinator 恢复默认 `FloatingTextFeedbackBackend`（见 `FeedbackPlaybackCoordinator.SetBackend` 源码第 69 行：`_backend = backend ?? new FloatingTextFeedbackBackend()`）。

当前实际挂载位置：
- `Assets/Scenes/SampleScene.unity` / `Canvas/FeelFeedbackInstaller`
- `Assets/Scenes/SampleScene.unity` / `Canvas/FeelFeedbackPlayers`

## 接线位置

- 结算、费用、即时金钱、贷款 → 继续走 `BaoZuPoFeedbackAdapter`，不改动。Composite 后端透明拦截。
- 卡牌拖拽 → `UICardDragController`，出牌成功时通过 `FeelFeedbackBackend.PlaySlotAt(FeelFeedbackSlots.CardPlay, position)` 在落点附近播放。
- 奖励面板 → `UICardRewardPanel`，面板展示时在面板中心播放，选中时在所选卡牌位置再次播放 `RewardReveal`。
- 玩法核心脚本 **不直接依赖** `MoreMountains.*`。所有 Feel 调用收口在 `Integration/Feel/` 和 UI 层。

## 降级策略

与项目原则对齐：**配置错误报错中断，功能缺失可降级。**

| 情况 | 行为 |
|------|------|
| `BaoZuPoFeelFeedbackInstaller` 未挂 / 场景中不存在 | 静默降级，FloatingText 照常工作，游戏不受影响 |
| Installer 存在但 `_bootstrap` 引用为 null | `Debug.LogError` + 自我禁用，不继续接线 |
| Installer 存在、bootstrap 有效，但某个 MMF_Player 为 null | `Debug.LogWarning`（Awake），对应类别跳过 Feel 增强，其余正常 |
| Feel 后端运行时 `MMF_Player.PlayFeedbacks()` 抛异常 | Composite 的 catch 吞掉异常并 `Debug.LogError`，主后端不受影响 |
