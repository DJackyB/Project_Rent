# 归档说明

`Doc/90_归档/` 存放已经落地、已经被新方案替代、或只保留历史价值的文档。

## 阅读原则

- 默认不要从归档文档恢复当前状态；先读 `Doc/README.md` 和 `Doc/10_模块梳理/`。
- 归档文档里的路径、类名、状态可能是当时快照，不保证与当前工程一致。
- 如果需要恢复旧方案，先写新的专题方案，不直接把旧文档移回活跃目录。

## 分类

- `专题方案/`：旧设计稿、已落地方案、已暂停方案。
- `评估审查/`：旧阶段 review、风险评估、历史数值分析。
- `代码审查/`：已被更新报告承接的代码审查。
- `阶段与日志/`：开发日志和阶段执行清单。
