# 开发日志 2026-03-25：跳字反馈模块抽离与资金全链路接入

## 本次目标

- 把结算专用跳字改造成通用反馈模块
- 保持模块关闭时游戏主流程不受影响
- 先完成资金全链路接入
- 同步补齐模块说明、专题方案和实现日志

## 本次主要改动

### 反馈模块骨架

- 新增 `Feedback/Core`
- 新增 `Feedback/Runtime`
- 新增 `Feedback/UI`
- 新增 `Feedback/Adapters/BaoZuPo`

### 启动与降级

- `UIManager` 启动时会创建 `FeedbackBootstrap`
- `GameConfig` 新增：
  - `enableFeedback`
  - `enableMoneyFeedback`
  - `enableFeedbackLogs`
- 关闭配置或初始化失败时，自动回退到 `NoOpFeedbackService`

### 旧结算链路迁移

- `UISettlementSequenceController` 从“直接播放器控制器”改为“兼容桥”
- 旧的 `SettlementSequenceQueued` 仍可继续发布
- 真正的播放逻辑改由通用反馈模块接管

### 资金反馈接入

- 房间/合同结算继续沿用原有结算语义，但输出转给新模块
- 出牌花费新增单次负向反馈
- 即时收益新增单次正向反馈
- 贷款成功新增全局负向反馈
