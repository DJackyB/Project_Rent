# 卡牌效果配置建议 v1（Excel 为唯一录入入口）

> 说明：以下是可直接填写到 `instantEffect / settleEffect` 等字段的建议值。
> 当前仍支持使用 `|` 组合多个效果。
> 状态：这是录表建议，不是运行时真源，也不是完整效果白名单；最终仍以导表结果、启动校验和 `CardEffectFactory` 支持范围为准。

## 事件卡

| 卡名 | 建议配置 |
|---|---|
| 强制退租 | `EvictTenantInSelectedRoom` |
| 短期续租 | `AddTenantDurabilityInSelectedRoom;2` |
| 临时加租 | `AddMoney;100` |
| 永久加租 | `AddTenantDurabilityInSelectedRoom;20` |
| 混响视听 | `TriggerSelectedRoomSettle` |
| 强制搬迁 | `MoveTenantToEmptyRoom` |
| 全网发布 | `SpawnRandomTenantInSelectedRoom` |

## 合同卡

| 卡名 | 建议配置 |
|---|---|
| 社恐 | `AddMoneyByEmptyRooms;50`（`settleEffect`） |
| 环境税 | `AddMoneyByRoomCount;100`（`settleEffect`） |

## 备注

- 以上“需要选房间”的效果名称仍沿用 `SelectedRoom` 命名约定，便于和启动校验保持一致。
- 新卡配置时不能只依赖效果命名，必须同时显式填写 `targetKind = Room`。
- 不需要选房间的卡，无论 `cardType` 是 `Tenant`、`Equipment`、`Event` 还是 `Contract`，都可以显式配置成 `targetKind = PlayArea`。
- 导表后资产生效，不建议长期手动编辑生成出来的 `ScriptableObject`。
