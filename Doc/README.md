## 维护规则

- 当前实现说明优先沉淀到 `10_模块梳理/`，不要继续把关键知识只留在开发日志里。
- 项目原则和协作共识统一追加到 `00_必读/项目开发必读.md`。
- 专题方案必须明确写清楚“当前是否已落地、是否仍在执行、是否已转为历史方案”。
- 导入模块不等于已经启用；模块是否接线、当前是否为真源，必须写进 `10_模块梳理/`。
- 当前有效文档中的文件路径应直接对应仓库真实路径，避免保留 `Assets/_Assets/...` 之类的历史路径。
- 历史文档统一放进 `90_归档/`，避免主目录继续堆时间性噪音。
- 外部资料只做参考，不作为当前实现真源。
