## 维护规则

- 当前实现说明优先沉淀到 `10_模块梳理/`，不要继续把关键知识只留在开发日志里。
- 专题方案必须写清楚状态：`执行中`、`设计中`、`已落地`、`已暂停` 或 `已归档`。
- 已落地且已有模块文档承接的方案，移动到 `90_归档/专题方案/`。
- 旧审查报告如果已有更新报告承接，移动到 `90_归档/代码审查/` 或 `90_归档/评估审查/`。
- 外部资料只做参考，不作为当前实现真源。
- 文档内路径如果随目录迁移变化，优先修模块文档和本导航；历史归档文档允许保留当时路径。
