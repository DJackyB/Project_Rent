# 跳字反馈模块

## 当前状态

- 状态：V1 已落地
- 位置：`Assets/_Assets/Scripts/Feedback/`
- 目标：在当前项目内形成可拔插的通用反馈模块，后续可继续抽成独立包

## 模块职责

- 接收业务层发出的通用反馈请求
- 按目标分轨播放跳字反馈
- 在模块不可用时自动降级为 NoOp
- 保证反馈播放失败不会中断游戏流程

## 目录结构

- `Core/`
  - 通用接口、请求模型、枚举
- `Runtime/`
  - 服务定位、NoOp 降级、播放协调器、启动入口
- `UI/`
  - 样式映射与通用浮字播放转换
- `Adapters/BaoZuPo/`
  - 当前项目的房间/合同/全局目标映射

## 公共接口

### `IFeedbackService`

- `bool IsAvailable`
- `void Publish(FeedbackRequest request)`
- `void PublishSequence(FeedbackSequenceRequest request)`

### 核心数据

- `FeedbackRequest`
  - 单次反馈
- `FeedbackSequenceRequest`
  - 多步序列反馈
- `FeedbackStep`
  - 序列中的单步

### 核心枚举

- `FeedbackCategory`
  - `Money`
  - `Settlement`
  - `Cost`
  - `Loan`
- `FeedbackTargetKind`
  - `Room`
  - `Card`
  - `Global`
- `FeedbackChannel`
  - `FloatingText`
  - `Sequence`

## 运行时结构

### 启动

- `UIManager` 在启动时创建并配置 `FeedbackBootstrap`
- `FeedbackBootstrap` 根据 `GameConfig` 决定启用真实服务还是 NoOp

### 播放

- `FeedbackPlaybackCoordinator` 维护“目标 key -> 播放轨道”的映射
- 单条轨道内部复用 `UISequenceTextController`
- 不同目标独立播放，互不抢占

### 降级

以下情况会自动退化到 NoOp：

- `enableFeedback = false`
- `enableMoneyFeedback = false`
- 启动入口未创建
- 播放器创建失败

退化行为：

- 业务照常执行
- 不等待反馈完成
- 不抛出阻断主流程的异常
- 只丢失跳字表现

## 当前项目适配

由 [BaoZuPoFeedbackAdapter.cs](../../Assets/_Assets/Scripts/Feedback/Adapters/BaoZuPo/BaoZuPoFeedbackAdapter.cs) 负责：

- 房间目标 -> 房间锚点
- 合同目标 -> 合同卡锚点
- 事件/贷款 -> 全局锚点或屏幕中心回退

当前 V1 已接入：

- 结算房租
- 结算加成
- 结算最终值
- 出牌花费
- 即时资金收益
- 贷款扣款

## 当前未做

- 等待跳字
- 独立 `asmdef`
- 外部包化
- 自定义可视化编辑器

## 后续扩展建议

- 如果要接耐久/等待，先把直接字段写入收口成统一入口
- 如果要迁移到别的项目，优先先抽 `Core + Runtime + UI`，再替换业务适配层
- 如果反馈种类继续增多，再考虑把样式配置提成 `ScriptableObject`
