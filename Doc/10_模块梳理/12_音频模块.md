## 架构

```
游戏逻辑 → EventBus → AudioEventBridge → AudioServices.Current → UnityAudioBackend
```

## 接线步骤（手工）

1. 在 `Assets/_Assets/Data/Audio/` 创建 `AudioCatalog.asset`（右键 → Martian > Audio > Audio Catalog）
2. 同目录创建 `AudioSettings.asset`（右键 → Martian > Audio > Audio Settings）
3. AudioSettings 配置：Pool Size = 16，Music Sources = 2，Fade = 0.5s
4. 主场景创建空 GameObject `[Audio]`，挂 `AudioBootstrap` + `AudioEventBridge`，引用两个资产

## Cue ID 列表

| cue id | Bus | pitchMin/Max | cooldown | 说明 |
|---|---|---|---|---|
| bgm.main | Music | 1 / 1 | 0 | 主循环 BGM |
| bgm.result | Music | 1 / 1 | 0 | 结算/游戏结束 BGM |
| sfx.card.play | Sfx | 0.95 / 1.05 | 0 | 出牌 |
| sfx.coin.gain | Sfx | 1 / 1 | 0.05 | 获得金币（含还贷正向） |
| sfx.coin.lose | Sfx | 1 / 1 | 0.05 | 扣除金币/还贷 |
| sfx.turn.start | Sfx | 1 / 1 | 0 | 回合开始 |
| sfx.reward.show | Sfx | 1 / 1 | 0 | 奖励面板展开 |
| sfx.reward.pick | Sfx | 1 / 1 | 0 | 选择奖励 |
| ui.button | Ui | 1 / 1 | 0 | 通用按钮点击 |

> Clips 留空，有音频资产后填入 AudioCatalog 对应条目的 `clips` 数组即可，代码不用动。

## AudioEventBridge 事件映射

| GameEvent | 播放 |
|---|---|
| `GameEvents.CardPlayed` | sfx.card.play |
| `GameEvents.TurnStarted` | sfx.turn.start |
| `GameEvents.CardRewardOffered` | sfx.reward.show |
| `GameEvents.CardRewardSelected` | sfx.reward.pick |
| `GameEvents.MoneyChanged`（Delta > 0） | sfx.coin.gain |
| `GameEvents.MoneyChanged`（Delta ≤ 0） | sfx.coin.lose |
| `GameEvents.GameOver` | PlayMusic("bgm.result") |
| OnEnable（系统启动） | PlayMusic("bgm.main") |
